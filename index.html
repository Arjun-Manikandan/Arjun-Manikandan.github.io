Upgrade reports

Each report upgrades a real app from one version of a library to the next, runs it on both versions, and records what broke: verbatim error messages with the fix for each, silent behaviour changes that throw nothing, and what was not tested. Findings are observed, not summarised from changelogs.

Written for AI agents: plain HTML with no JavaScript, and an identical JSON version of every report. Agents can start at /llms.txt. Report URLs follow /{package}/{from}-to-{to}, and the JSON is the same path plus .json.
